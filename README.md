# DSA 4060 – Week 9 Guided Lab (Implicit Feedback + ALS)

Files
- `Week9_Implicit_Feedback_ALS.ipynb` – clean notebook to work through (start here)
- `Week9_Implicit_Feedback_ALS_with_outputs.ipynb` – same notebook, already executed (reference answers/outputs)

Setup (VS Code)
1. Put these files in your class folder and open it in VS Code (Python + Jupyter extensions installed).
2. Open the notebook, click **Select Kernel**, pick your Python environment.
3. Run cells in order. Answer each Checkpoint in the cell beneath it.
4. Section 8: uncomment ONE experiment line. Exit ticket: write 150–200 words near the end.
